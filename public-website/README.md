# OptimIQ public website — draft 02

Status: awaiting client feedback. Replaces draft 01 as the primary review concept following user feedback that the earlier design looked generic and AI-generated. This is an authorized redesign of the public website only; the member portal baseline is unchanged.

Direction: editorial typography, people-led photography, sharp edges, open layouts and direct audience sections. Uses the approved forest/mint palette and supplied logo. Manrope variable font is locally hosted, with its OFL license included. Font source: https://github.com/google/fonts/tree/main/ofl/manrope . Photography: Christina Morillo, https://www.pexels.com/photo/group-of-people-on-conference-room-1181396/ . The photo is illustrative stock, not an OptimIQ team or client representation.

Static HTML/CSS/JavaScript for GitHub Pages review, with native disclosure controls, responsive layouts and a local consultant workload calculator. Component boundaries for later Next.js implementation: Header, EditorialHero, AudienceIndex, Introduction, ClientExpertiseAccordion, ConsultantPlanner, FirmWays, OnboardingSteps, Closing, Footer. The inputs calculate a workload scenario only. They are not stored, transmitted or used as official CTQ scores.

Canonical review entry: public-website/index.html in the existing repository. Existing CTA forms remain linked. Portal sign-in is the current static review screen. Public privacy/terms content, production CTA destinations, client/firm hook calculators, Arabic content and actual service availability need later scope/approval.
